# unix-env

Переносимое окружение Unix для macOS и Ubuntu.

## Очистка

`cleanup.sh` содержит отметку `users-managed` для ручного сопровождения. Окружение считается полностью настроенным: Bash 5+, GNU sort под именем `sort`, uv, fnm, npm и Homebrew. Проверок наличия программ, выбора альтернативных команд и проверки прав нет.

Запуск сразу выполняет очистку:

```bash
./cleanup.sh
```

Параметров и режима просмотра нет. Ошибка любой команды останавливает выполнение. Переменная `HOME` не изменяется.

Среди стабильных выпусков CPython сохраняется последняя установленная версия каждой ветки `3.x` отдельно для каждой сборки и платформы. Например, из нескольких версий `3.13.x` и `3.15.x` останется по одной последней. Для стабильных выпусков Node.js сохраняется последняя версия каждой основной ветки, например последняя `24.x`. Предварительные выпуски и другие реализации Python пропускаются.

Текущие интерпретаторы, виртуальные окружения, программы `uv tool` и псевдонимы fnm не защищают старую версию от удаления. Удаление Python может нарушить зависимые окружения, а удаление Node.js также удаляет глобальные пакеты и псевдонимы этой версии.

Очистка кэшей использует `uv cache prune`, `npm cache clean --force` и `brew cleanup`. На Ubuntu также выполняется `sudo apt-get clean`. Кэш npm очищается до удаления Node.js. Содержимое кэшей при необходимости загружается повторно.

Сценарий не удаляет пользовательские документы, каталоги проектов, корзину, общие каталоги кэшей, данные Docker и системные журналы.
