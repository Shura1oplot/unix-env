# Описание проекта

## Назначение

Проект хранит переносимые файлы среды Unix и сценарии их установки и обновления на macOS и Linux.

## Цели

1. Поддерживать одинаковое пользовательское окружение на рабочих системах.

2. Не изменять файлы другого пользователя при запуске сценариев с правами `root`.

3. Сохранять простые сценарии с проверяемым поведением.

## Критерии выполнения текущей задачи

1. Вызовы `du`, `df`, `ls`, `grep` и `find`, выводящие результат в терминал, печатают в `stderr` краткую рекомендацию современной замены.

2. При передаче вывода в конвейер или файл подсказка не печатается.

3. Исходная команда получает аргументы без изменений, а ее код возврата сохраняется.

4. Вызов через `command` позволяет запустить исходную команду без подсказки.

5. Автоматическая проверка покрывает терминал, конвейер, перенаправление и код возврата.

6. Проектные проверки и обязательные проверки Zsh и Bash завершаются без ошибок.

## Ограничения

1. Значение переменной `HOME` не изменяется вызывающим процессом.

2. Обертки действуют только в интерактивной конфигурации Zsh.

3. Изменения ограничиваются обертками, их проверками и необходимыми изменениями установки.
