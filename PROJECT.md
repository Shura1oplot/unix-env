# Описание проекта

## Назначение

Проект хранит переносимые файлы среды Unix и сценарии их установки и обновления на macOS и Linux.

## Цели

1. Поддерживать одинаковое пользовательское окружение на рабочих системах.

2. Не изменять файлы другого пользователя при запуске сценариев с правами `root`.

3. Сохранять простые сценарии с проверяемым поведением.

## Критерии выполнения текущей задачи

1. После глобального обновления `update.sh` запускает штатную строгую проверку npm для заблокированных установочных сценариев.

2. Если проверка находит заблокированные сценарии, в интерактивном режиме сценарий один раз запрашивает подтверждение `y/n`; безопасный ответ по умолчанию — отказ.

3. При подтверждении все установочные сценарии глобального дерева выполняются один раз через `--dangerously-allow-all-scripts`.

4. При отказе или неинтерактивном запуске установочные сценарии остаются заблокированными, а обновление продолжается.

5. Вывод npm не захватывается и не разбирается регулярными выражениями.

6. Обязательные проверки Bash завершаются без ошибок.

## Ограничения

1. Значение переменной `HOME` не изменяется вызывающим процессом.

2. Разрешения новых npm пакетов не записываются в пользовательский `.npmrc`.

3. Изменения ограничиваются обработкой глобальных npm-команд в `update.sh` и необходимой настройкой ShellCheck.
