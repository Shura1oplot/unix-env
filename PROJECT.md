# Описание проекта

## Назначение

Проект хранит переносимые файлы среды Unix и сценарии их установки и обновления на macOS и Linux.

## Цели

1. Поддерживать одинаковое пользовательское окружение на рабочих системах.

2. Не изменять файлы другого пользователя при запуске сценариев с правами `root`.

3. Сохранять простые сценарии с проверяемым поведением.

## Критерии выполнения текущей задачи

1. `sync-agent-env.sh` обновляет настройки текущего пользователя.

2. Сценарий обновляет настройки проекта только в каталоге, принадлежащем текущему пользователю.

3. Запуск от `root` не изменяет настройки проектов в каталоге другого пользователя.

4. Автоматическая проверка воспроизводит ошибку и проходит после исправления.

5. `shellcheck`, форматирование Bash и проектные проверки завершаются без ошибок.

## Ограничения

1. Значение переменной `HOME` не изменяется вызывающим процессом.

2. Внешнее поведение сценария сохраняется для каталогов, принадлежащих текущему пользователю.

3. Изменения ограничиваются причиной ошибки и проверками для нее.
